# React State and Events

## Lesson 1: Local State with useState

Learning objective:
Understand how React stores local component state with `useState` and why state drives re-rendering. Learn when a value should be state instead of a regular variable.

Practical outcome:
Build a small interactive counter that updates the UI from component state.

## Lesson 2: Updating State Safely

Learning objective:
Learn how state updates are scheduled and why the next state can depend on the previous state. Practice using updater functions for reliable changes.

Practical outcome:
Build controls that increment, decrement, and reset state without relying on stale values.

## Lesson 3: Handling User Events

Learning objective:
Learn how React event handlers work with clicks, form actions, and keyboard input. Understand how to pass handler functions without calling them during render.

Practical outcome:
Build a simple interaction panel with multiple buttons and clear event handler responsibilities.

## Lesson 4: Controlled Form Inputs

Learning objective:
Understand controlled inputs and how form values can be stored in React state. Learn how `value` and `onChange` work together for predictable form behavior.

Practical outcome:
Build a controlled text input that previews and clears user input.

## Lesson 5: Derived UI State

Learning objective:
Learn how to derive display values from existing state instead of duplicating data. Practice keeping state minimal and using render logic for UI conditions.

Practical outcome:
Build a small status component that shows different messages based on current state.

## Lesson 6: State and Events Practice

Learning objective:
Combine local state, safe updates, event handlers, controlled inputs, and derived UI state in one focused exercise. Reinforce React 19-friendly patterns without introducing advanced Hooks topics.

Practical outcome:
Build a small interactive task list with add, toggle, filter, and reset behavior.
